# Cihaz Kontrol v0.13.2 — Sıfır dolgulu IP adresleri düzeltildi

**Düzeltme:** Bazı cihazlar (ör. Rohde & Schwarz HMP4040) IP adresini baştaki sıfırlarla gösterir: `192.168.010.010`. Bu yazım uygulamaya aynen girilince Windows baştaki sıfırlı bölümleri sekizlik sayı sayıp adresi **192.168.8.8** diye çözüyordu; bağlantı yanlış adrese gidiyordu. Uygulama artık baştaki sıfırları kendisi atıyor (`192.168.10.10`); daha önce bu biçimde kaydedilmiş cihazlar da doğru adrese bağlanıyor.

**Belge:** README'deki HMP4040 bölümü düzeltildi: doğru menü yolu (**MENU → INTERFACE → ETHERNET → SETTINGS**), DHCP notu, doğrudan kabloyla bağlantı için PC IP ayarı ve MAC adresinin nasıl bulunacağı.

**Windows x64:** `CihazKontrol-0.13.2-portable.exe` (taşınabilir) / `Cihaz Kontrol Setup 0.13.2.exe` (kurulumlu). İmzasız — SmartScreen'de "Ek bilgi → Yine de çalıştır".

Doğrulama: sıfır dolgulu adresle ekleme ve bağlanma testi eklendi; tüm testler yeşil; uçtan uca test geçti.
