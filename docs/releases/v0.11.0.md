# Cihaz Kontrol v0.11.0 — Mini-Circuits sinyal üreteçleri (USB)

**Yeni:** Mini-Circuits **SSG-6000RC** (25–6000 MHz, −65…+14 dBm) ve **SSG-15G-RC** (10 MHz–15 GHz, −45…+10 dBm) sinyal üreteçleri USB üzerinden kontrol edilebiliyor. Kenar çubuğunda yeni **Sinyal Üreteçleri** kategorisi var: frekans (MHz) ve güç (dBm) ayarı, RF çıkışı aç/kapat, değerler cihazdan geri okunur. Cihaz eklerken takılı USB cihazları taranır ve seri numarasıyla seçilir. Sürücü kurulumu gerekmez. Kablo çekilince uygulama yeniden bağlanmayı bekler, takılınca döner.

Mevcut cihazlar (CPX400DP, E36233A, N5745A, Hardware Server) değişmedi.

**Not:** USB komut biçimi henüz gerçek cihazla doğrulanmadı. Sorun olursa ekleme penceresindeki uyarıyı ve SCPI konsolunda `:FREQ?`, `:PWR?`, `:PWR:RF?` yanıtlarını bildirin.

**Windows x64:** `CihazKontrol-0.11.0-portable.exe` (taşınabilir) / `Cihaz Kontrol Setup 0.11.0.exe` (kurulumlu). İmzasız — SmartScreen'de "Ek bilgi → Yine de çalıştır".

Doğrulama: 175 test yeşil; uçtan uca test (sahte USB cihazlarıyla) geçti. Bu sürümden itibaren release'ler GitHub Actions'ta otomatik derlenip yayınlanır.
