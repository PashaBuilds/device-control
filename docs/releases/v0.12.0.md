# Cihaz Kontrol v0.12.0 — SSG sinyal üreteçleri USB'de çalışıyor (ikili protokol)

**Düzeltme:** SSG-6000RC ve SSG-15G-RC USB'de "cihaz bulunamadı" hatası veriyordu. Uygulama bu cihazlara USB üzerinden SCPI metni gönderiyordu; cihazlar ise USB'de Mini-Circuits'in ikili komut kodlarını kullanıyor. Sürücü, Mini-Circuits programlama kılavuzunun (Signal Generators Programming Manual C3, bölüm 5) ikili protokolüne göre yeniden yazıldı:

- Tanıma: model (40), seri no (41), ürün yazılımı (99)
- Ayar: frekans (101 — SSG-6000RC'de 5 baytlık Hz, SSG-15G-RC'de MHz metni), güç (102), RF aç/kapat (104)
- Geri okuma: durum (105) — RF açık/kapalı, frekans, güç, kilit durumu

**Yeni:** Panel cihazın bildirdiği uyarıları gösteriyor: "frekans kilitli değil" ve "istenen güç cihazın bu frekanstaki sınırının dışında". SCPI konsolu USB üzerinden çalışıyor (`:FREQ?`, `:PWR?`, `:PWR:RF?` …). Tanılama raporu artık durum ve SCPI yanıtlarını da gösteriyor.

**Windows x64:** `CihazKontrol-0.12.0-portable.exe` (taşınabilir) / `Cihaz Kontrol Setup 0.12.0.exe` (kurulumlu). İmzasız — SmartScreen'de "Ek bilgi → Yine de çalıştır".

Doğrulama: kılavuzdaki örnek paketler birebir test edildi; 181 test yeşil; uçtan uca test (sahte USB cihazlarıyla) geçti. Gerçek cihazla ilk denemede bulunamama ya da yanlış değer görülürse Tanılama raporunu gönderin.
